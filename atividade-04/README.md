## Enunciado: Sensor de Temperatura e LEDs

O projeto utiliza um **sensor de temperatura** como entrada para controlar **três LEDs** como saída. O Arduino realiza a leitura da temperatura e, de acordo com o valor identificado, aciona os LEDs para indicar diferentes faixas de temperatura.

- O Arduino realiza a leitura da **temperatura por meio do sensor**.
- Os LEDs são utilizados para **indicar diferentes níveis de temperatura**.
- Cada LED representa uma **faixa de temperatura**, permitindo visualizar de forma simples a variação da temperatura detectada.

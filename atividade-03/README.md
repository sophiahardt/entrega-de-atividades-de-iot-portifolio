## Enunciado: LED com Sensor de Presença

O projeto utiliza um **sensor de presença** como entrada para controlar um **LED** como saída. Quando o sensor detecta a presença de uma pessoa ou movimento, o Arduino aciona o LED. Quando não há presença detectada, o LED permanece desligado.

- O Arduino recebe as informações do **sensor de presença**.
- O Arduino controla o **LED** de acordo com a detecção de presença.
- O LED é acionado quando o sensor identifica movimento ou presença.
